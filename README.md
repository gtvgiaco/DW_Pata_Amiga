# DW_Pata_Amiga
 Este projeto é uma atividade avaliativa do curso de análise de dados do SCTEC, módulo 2.  O objeto é implementar um Data warehouse para a rede de petshops **Pata Amiga**.  O projeto contempla a modelagem dimensional, tratamento de dados de staging, carga da tabela fato/dimensões e respostas orientadas a perguntas de negócio usando o MySQL.
